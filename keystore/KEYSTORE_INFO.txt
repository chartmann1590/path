========================================
BIBLE STUDY APP - RELEASE KEYSTORE INFO
========================================

Do not store release keystore passwords, aliases, API tokens, AdMob IDs, or Firebase
configuration values in this repository.

Release signing is configured through GitHub repository secrets:

- RELEASE_KEYSTORE_BASE64
- RELEASE_STORE_PASSWORD
- RELEASE_KEY_ALIAS
- RELEASE_KEY_PASSWORD

Firebase, AdMob, and in-app GitHub feedback configuration are also configured through
GitHub repository secrets. See ../.github/SECRETS.md for the full required list.

Keep offline backups of the release keystore in secure storage. If the release key is
lost, app updates may require Google Play App Signing recovery or a new app listing.
